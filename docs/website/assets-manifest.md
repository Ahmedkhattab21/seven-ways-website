# Local marketing asset manifest

Source: `https://seven-ways.com/`. All presentation assets below are served from
`public/assets/website`; the marketing layout does not hotlink them.

For every retained source file, the original URL is
`https://seven-ways.com/assets/{file}` and the local URL is
`/assets/website/{type}/{file}`.

  to avoid external-SVG namespace issues.
- Three source production CSS bundles are retained in
  `public/assets/website/reference-css` for audit/reference only and are not loaded
  by Laravel.
